# PocketLedger v0.1.0 candidate

Includes offline finance tracking, CSV and SMS import, tuition management, monthly budgets, reports, and SQLCipher local database encryption.

This is a build candidate, not a released or device-validated APK. The signed APK is first uploaded as a GitHub Actions artifact for user inspection.

Direct APK includes READ_SMS for user-initiated inbox import. Google Play permission eligibility must be reviewed separately.

For updates, preserve application ID and signing certificate and increase versionCode.
